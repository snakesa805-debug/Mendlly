# Mendlly (Ular Neon)

Login menggunakan **Username + Password** saja (tanpa Gmail/Google).

## Build APK

GitHub Actions akan otomatis build APK saat push ke `main` (folder `game/**`).

Atau trigger manual dari tab Actions → Android APK → Run workflow.

APK akan muncul di:
- Artifacts
- Releases (tag `latest`)
